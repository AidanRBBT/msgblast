# msgblast 0.3.0

## Compare your web agents in one Mac app

Muse, ChatGPT, Claude, and Grok now appear in My agents alongside your Messages agents. Select the agents you want, write one request, and use Send & compare to view their conversations side by side inside msgblast.

- All four web agents start selected. Use their checkmarks to change recipients; your selection is remembered.
- Each service opens in an embedded browser pane, with its own persistent sign-in session. You can read replies and use the service's normal chat controls without switching to a separate browser window.
- Muse uses your signed-in Muse avatar when it can be read, with its default website image as a fallback. The other web agents have their own artwork.
- Claude opens at claude.ai. Grok uses grok.com; the unavailable Grok Bot desktop entry is removed.

## Keep each Blast in its own conversations

Each new Blast gets a dedicated conversation in every selected web service. Muse requests go to a side chat rather than its main chat. Follow-ups continue in those same conversations, and selecting a saved comparison reopens the saved chats.

Use New Blast to start a separate comparison. The toolbar now uses a compose icon with a visible label and consistent padding. Add Agent also has a visible label. The wider initial window gives side-by-side chats more room while staying within the current display.

## Sign in without losing your request

The first shared request opens account setup if a selected service needs it. Your prompt stays in the shared composer while you sign in to the individual services. After signing in, press Send & compare again; login never submits your request automatically.

Your Safari, Chrome, and desktop-app logins remain separate from msgblast's embedded sessions. Sign in once inside msgblast for each service. Supported sign-in popups stay inside the app.

## More reliable sends and follow-ups

- ChatGPT's current editor, Send button, and outgoing-message markup are recognized, including narrow comparison layouts.
- Grok follow-ups wait for its Submit button to become ready and recognize its response identifier without treating the same conversation as a different destination.
- Existing website drafts are preserved. If a draft, conversation, or control changes before submission, msgblast stops instead of guessing.
- Submission intent is saved before clicking Send. The app then looks for the outgoing message in that conversation. An interrupted or unconfirmed send is never retried automatically.
- A missing login keeps the shared request available without sending it to other selected recipients during setup. Retrying a failed Messages recipient does not resend web requests.

## A quieter comparison workspace

Confirmed sends no longer leave an Appeared in… banner or repeat your prompt above each chat. Sending progress, failures, and unconfirmed results remain visible when they need attention.

Temporary sign-in and dialog warnings clear when the intended chat becomes ready. Redundant Open buttons and Needs attention badges have been removed. Each pane keeps its Reload control. ChatGPT's expanded sidebar closes on initial setup, while msgblast's sidebar stays open; later manual changes to ChatGPT's sidebar are respected.

## Compatibility and scope

- Requires macOS Sequoia 15 or later, retaining the compatibility work from 0.2.1 and the clearer Messages connection prompt from 0.2.2.
- Shared requests that include web agents are text-only. Messages-only workflows retain their existing attachment support.
- Models and thinking settings use each website's current settings. msgblast does not automatically choose a model or thinking level.
- A confirmed send means the outgoing text was observed in the page, not a server delivery acknowledgement. Website updates, sign-in requirements, and unrecognized layouts can affect shared submission; the embedded page remains available for direct use.
- The repository is now licensed under GPLv3. Separately licensed dependencies and artwork retain their own terms.
