# msgblast 0.6.0

- Discover brings contact search, manual agent entry, and the agent directory into one page. The directory is now called Additional Agents.
- Connect Messages first, then Contacts, with setup prompts above search that disappear after access is granted.
- Known agents in Contacts appear automatically by name, including Fo, Szn, Instinct, and agents in the directory. Search updates as you type.
- Saved agents have a remove control. New Blast is available at the top of Discover.
- Sidebar rows are clickable across their full width, with rounded selection bars and titles and icons that dim when the window loses focus.
