# msgblast 0.5.1

- Optional Codex CLI and Claude Code conversations now load your configured skills, tools, and connectors while respecting CLI permissions. Comparison summaries keep their restricted tool policy.
- Existing CLI conversations retain their history and drafts when moving to a configured session. Follow-ups continue in the new session.
- Claude Code permission denials are shown explicitly. Claude Code conversations require version 2.1.259 or later.
- Includes the updated green app icon and keeps development/demo builds visually distinct.
- Preserves the latest web-navigation fixes, including canceling a pending send when you leave its chat before submission.
- Development previews keep their data and settings separate from the installed app.
