# msgblast 0.7.0

- Add Grok Bot as a separate agent, with replies inside msgblast through an app-managed temporary tunnel.
- Include the tunnel helper in the app so Grok Bot setup needs no Homebrew installation.
- Remember the Grok Bot connection across relaunches and app updates using hardware-encrypted storage, without Mac login-password prompts.
- Open Grok Bot settings from the chat header's gear and remove the chat-count navigation strip.
