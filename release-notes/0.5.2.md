# msgblast 0.5.2

- Fixes an update/quit deadlock when saved state cannot be loaded. The original state stays untouched, and new drafts and attachment references are saved separately in a private recovery folder before quitting.
- Sending remains disabled while saved state cannot be loaded. If recovery cannot be saved, the app stays open.
- Already stuck on an older version? Copy any unsaved text, Force Quit msgblast, download the latest app from https://updates.msgblast.app/latest.zip, and replace only the app in Applications. Keep the msgblast folder in Application Support: it contains your saved comparisons and drafts. See the recovery guide for backup and installation steps.
