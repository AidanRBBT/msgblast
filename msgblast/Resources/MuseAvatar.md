# Muse avatar

`MuseAvatar.jpg` is the unchanged avatar image referenced by the Muse website, downloaded October 2, 2026 from https://muse.ai/images/landing/brand/hatch.jpg.

It is the fallback in the agent picker, embedded chat header, and connection screen. After connecting, MsgBlast prefers a still of the personalized avatar displayed in the signed-in main chat. That image stays in memory and is cleared on sign-out, navigation, or loss of a readable avatar. The bundled fallback does not require sign-in or a network request. The existing circular avatar view supplies the crop.
