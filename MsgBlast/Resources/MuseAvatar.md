# Muse avatar

`MuseAvatar.jpg` is the unchanged avatar image referenced by the Muse website, downloaded October 2, 2026 from https://muse.ai/images/landing/brand/hatch.jpg.

It identifies Muse in the agent picker, embedded chat header, and connection screen. The app bundles it so displaying the default avatar does not require sign-in or a network request. The existing circular avatar view supplies the crop.
